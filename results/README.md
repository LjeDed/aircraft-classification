# Результаты эксперимента

Здесь находятся CSV-файлы с предсказаниями и сравнением моделей, а также графики.

- `results_qwen.csv` — ответы Qwen2.5-VL-3B.
- `results_smolvlm.csv` — ответы SmolVLM2-2.2B.
- `metrics_summary.csv` — метрики по всей выборке и двум группам сложности.
- `comparison.csv` — объединённая таблица истинных меток и предсказаний.
- `confusion_matrices.png` — матрицы ошибок.
- `errors_grid.png` — примеры ошибок.

Исходные изображения не включены в репозиторий.
